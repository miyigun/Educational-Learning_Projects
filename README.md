# Educational-Learning_Projects

This repository contains **educational projects, learning notes, and practice examples** focused on **Android development and Java fundamentals**.  
The goal is to build a strong foundation through small, structured examples and mini projects.

---

## Categories / Folders

### 1. Android_Intents-Functions
- Intent usage examples (explicit / implicit)
- Activity navigation and data passing
- Common Android intent-based functions and scenarios

### 2. Android_UI_Examples
- UI component examples
- Layout practices (basic screens and patterns)
- Simple UI experiments and reusable patterns

### 3. Form-Input_Examples
- Form and input handling examples
- Validation logic and user feedback patterns
- Text fields, selections, and basic input workflows

### 4. Java_Bootcamp_Projects
- Bootcamp-style mini projects
- Practice apps and console-based examples
- Step-by-step learning projects

### 5. Java_OOP-Intro
- Object-Oriented Programming basics
- Classes, objects, inheritance, polymorphism examples
- OOP-focused practice snippets

---

## Getting Started

To run the projects:

1. Clone the repository:
   ```bash
   git clone https://github.com/miyigun/Educational-Learning_Projects.git
   ```

2. Navigate to the folder:
   ```bash
   cd Educational-Learning_Projects
   ```

3. Open a project depending on its type:
   - **Android projects:** Open the related folder with **Android Studio**, then build & run.
   - **Java projects:** Open with **IntelliJ IDEA / Eclipse** or compile via terminal.

4. (Optional) Running Java from terminal:
   ```bash
   javac Main.java
   java Main
   ```
