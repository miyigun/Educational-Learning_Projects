# Educational-Learning_Projects

Bu repo, **Android geliştirme ve Java temelleri** odaklı **eğitsel projeleri, öğrenme notlarını ve pratik örnekleri** içermektedir.  
Amaç, küçük ve düzenli örnekler ile sağlam bir temel oluşturmaktır.

---

## Kategoriler / Klasörler

### 1. Android_Intents-Functions
- Intent kullanım örnekleri (explicit / implicit)
- Activity geçişleri ve veri taşıma
- Intent tabanlı yaygın fonksiyonlar ve senaryolar

### 2. Android_UI_Examples
- UI bileşen örnekleri
- Layout çalışmaları (temel ekranlar ve yapılar)
- Basit arayüz denemeleri ve tekrar kullanılabilir desenler

### 3. Form-Input_Examples
- Form ve kullanıcı girdi yönetimi örnekleri
- Doğrulama (validation) ve kullanıcıya geri bildirim yaklaşımları
- Metin alanları, seçimler ve temel input akışları

### 4. Java_Bootcamp_Projects
- Bootcamp tarzı mini projeler
- Pratik uygulamalar ve console örnekleri
- Adım adım öğrenme projeleri

### 5. Java_OOP-Intro
- Nesne Yönelimli Programlama (OOP) temelleri
- Class, object, inheritance, polymorphism örnekleri
- OOP odaklı pratik kod parçaları

---

## Başlangıç

Projeleri çalıştırmak için:

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/miyigun/Educational-Learning_Projects.git
   ```

2. Klasöre girin:
   ```bash
   cd Educational-Learning_Projects
   ```

3. Proje türüne göre açın:
   - **Android projeleri:** İlgili klasörü **Android Studio** ile açın, ardından build & run.
   - **Java projeleri:** **IntelliJ IDEA / Eclipse** ile açın veya terminalden derleyin.

4. (Opsiyonel) Java’yı terminalden çalıştırma:
   ```bash
   javac Main.java
   java Main
   ```
